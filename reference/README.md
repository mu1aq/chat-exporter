# Shared Chat Exporter workspace

현재 구현은 [Python 통합 프로젝트](claude-share-extract/UNIFIED.md)입니다.

- ChatGPT와 Claude 공개 공유 링크 지원
- 전체 브랜치, 원시 응답, 도구/사고/인용 블록, Artifact 버전, 첨부 메타데이터 보존
- PNG를 포함한 공개 바이너리 자산과 전체 페이지 스크린샷 저장
- manifest와 SHA-256 감사 파일로 누락·불확실성 및 변조 확인

chatgpt-share-exporter 디렉터리는 이전 JavaScript 참고 구현으로 남겨 두었으며 실행 경로에는 포함되지 않습니다. 새 기능과 수정은 Python 프로젝트에서만 관리합니다.
